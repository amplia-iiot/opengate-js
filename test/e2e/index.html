opengate-js — API coverage in a browser

Walks the client surface against a live OpenGate from a real browser engine. Every check in the default lanes is a read, and each search is capped at one row.

Credentials are never stored. They are used for this run only.
# Outcome Lane Factory Call Result ms
pass
2xx.
empty
204, or a 404 saying the resource is not there. The call worked.
denied
401 or 403. The call worked; this credential may not do that.
absent
the endpoint is not served by this platform.
fail
anything else. This is the column that matters.
skip
not attempted; the reason is in the result column.
